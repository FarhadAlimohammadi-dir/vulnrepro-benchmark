API Endpoints:

  • GET /api/documents/list - List documents
  • GET /api/documents/search?q=term - Search documents
  • GET /api/reports/list - List reports
  • GET /api/reports/preview?file=report.html - Preview report
  • GET /api/admin/audit - View audit logs (admin)
  • GET /api/admin/stats - System statistics (admin)

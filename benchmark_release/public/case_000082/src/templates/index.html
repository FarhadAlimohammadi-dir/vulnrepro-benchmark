Quick Start API

# Login
POST /api/v1/auth/login
{"username": "your-username", "password": "your-password"}

# List your projects
GET /api/v1/projects
Authorization: Session cookie

# Create a project
POST /api/v1/projects
{"name": "My Project", "description": "Project description"}

# Generate API token
POST /api/v1/tokens
{"label": "CI Pipeline"}

Community Theme Marketplace

Discover Beautiful Themes

Browse, download, and activate community-crafted themes. Upload your own creations and share them with the world.

API Endpoints

  • GET /api/themes — List approved themes
  • POST /api/auth/login — Authenticate
  • POST /api/themes/upload — Upload a theme archive
  • POST /api/themes/:id/activate — Activate a theme
  • POST /api/themes/:id/rate — Rate a theme
  • GET /api/marketplace/search?q= — Search themes
  • GET /api/marketplace/featured — Featured themes

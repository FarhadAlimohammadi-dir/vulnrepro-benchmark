DocManager

API v1/v2 Multi-Tenant

Authentication

  • POST/api/v1/auth/loginAuthenticate and receive session token
  • POST/api/v1/auth/logoutInvalidate current session
  • GET/api/v1/auth/meGet current user profile
  • POST/api/v2/auth/actorExchange actor token for session

Documents

  • GET/api/v1/documentsList accessible documents
  • POST/api/v1/documentsCreate a document
  • GET/api/v1/documents/:idGet document by ID
  • POST/api/v1/documents/:id/shareShare with another tenant
  • GET/api/v1/documents/search?q=Search documents

Integration Tokens

  • POST/api/v1/integration/tokenGenerate cross-tenant actor token
  • GET/api/v1/integration/tokensList tokens (admin)
  • POST/api/v1/integration/tokens/:id/revokeRevoke a token (admin)
  • GET/api/v1/integration/relationshipsList tenant integrations

Administration

  • GET/api/v1/admin/usersList tenant users (admin)
  • GET/api/v1/admin/auditView audit logs (admin)
  • GET/api/v1/admin/settingsTenant settings (admin)

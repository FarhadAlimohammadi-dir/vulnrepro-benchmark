Attended Sysupgrade Build Service

Generate custom OpenWrt firmware images with your selected packages and target hardware profile.

Multi-target Support

Supports x86/64, ath79, ipq40xx, ramips and more hardware families across multiple OpenWrt release branches.

Build Caching

Identical requests return cached firmware immediately, reducing build time for common configurations.

Audit Trail

All build events are logged for compliance and operational review by the security team.

Quick Start

curl -s -X POST {{ request.host_url }}login \
  -H 'Content-Type: application/json' \
  -d '{"username":"builder","password":"builder456"}' | jq .session_id

Then use the returned session_id as the X-Session-ID header for subsequent requests.

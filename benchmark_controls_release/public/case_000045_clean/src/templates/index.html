⚡ NoteSync API v2

Meeting Notes, Synced.

NoteSync captures, transcribes, and syncs your meeting notes to Obsidian, Notion, Slack, and more. Integrate with any tool using our REST API.

Authentication

All API requests require a Bearer token in the Authorization header.

POST/api/v1/login
GET/api/v1/profile

Documents

Fetch, search, and manage your meeting documents and transcripts.

POST/api/v2/get-documents
GET/api/v2/search?q=

Integrations

Connect Notion, Obsidian, Slack, Confluence, and Linear for automatic sync.

POST/api/v2/integrations
POST/api/v2/export

Desktop Client Sync

The NoteSync desktop client fetches credentials on startup for offline token caching.

GET/api/v1/credentials/:username

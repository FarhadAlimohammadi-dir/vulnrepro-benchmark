gRPC Platform v2.4.1

Enterprise service gateway with gRPC-Web transcoding bridge. Internal microservices communicate via the gRPC bridge; external clients use the REST API.

REST API Endpoints

POST /api/auth/login

Authenticate and receive a session token.

GET /api/users/profile

Retrieve authenticated user profile. Requires Authorization: Bearer <token>

GET /api/reports/

List reports accessible to the authenticated user.

GET /api/admin/audit

Audit log access (admin only).

gRPC-Web Bridge

POST /api/grpc-web/v1/UserService/GetUserProfile

Fetch user profile via gRPC-Web framing.

POST /api/grpc-web/v1/SearchService/Search

Full-text search across published reports.

Health

GET /health

Service health check endpoint.

Developer Documentation

The People API lets you look up, list, and search person resources across the platform. All requests require a valid X-Goog-Api-Key header.

Available Endpoints

Method Path Description
GET /$discovery/rest Retrieve the API discovery document
GET /v1/people List people (supports pageSize)
GET /v1/people/{resourceName} Get a single person by resource name
GET /v1/search/people Search people by name or email (param: q)
GET /healthz Service health check

Authentication

Pass your API key via the X-Goog-Api-Key request header. Internal tooling endpoints additionally require X-Internal-Token.

Rate Limits

Default quota: 1,000 requests/minute per key. Contact the platform team to request increases.
